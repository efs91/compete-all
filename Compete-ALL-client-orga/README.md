# Compete-All - Interface Organisateur

Interface web pour les organisateurs d'événements utilisant l'API Compete-All.

## Fonctionnalités

- Créer et gérer des événements
- Associer des phases aux événements
- Gérer les inscriptions des participants
- Générer automatiquement les poules et tableaux
- Saisir les résultats
- Consulter les classements
- Piloter le déroulement de l'événement

## Installation

1. Installer les dépendances :
```bash
pip install -r requirements.txt
```

2. Lancer l'application :
```bash
python app.py
```

3. Accéder à l'interface : http://localhost:5001

## Configuration

L'API est configurée pour pointer vers : `https://benribs.fr/compete-all`
